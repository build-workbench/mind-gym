# Learning Path

New readers can treat this site as a short course. Start with the overview pages to understand the training goals, continue with the architecture section to learn how state, storage, and offline behavior are organized, and finish with the reference section when you need file-level orientation.

Contributors who want to change the game should also cross-check the OpenSpec materials in the main repository. The docs here are an entry ramp, while the specs remain the source of truth for implementation constraints.
