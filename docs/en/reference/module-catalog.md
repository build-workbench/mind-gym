# Module Catalog

The runtime centers on a few key modules: `app.js` orchestrates the experience, `src/game-state.js` coordinates live session state, and deep modules such as `src/game-manager.js` and `src/modal-manager.js` hide focused complexity behind small interfaces. Supporting modules cover storage, statistics, FSRS scheduling, i18n, and effects.

This catalog is a guidepost rather than a full API reference. It helps readers map documentation sections back to the files they will inspect in the repository.
