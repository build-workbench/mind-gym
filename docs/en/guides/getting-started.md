# Getting Started

If you are here to play, open the live demo from the navigation bar and choose a training mode that matches your available time. If you are here to contribute, read the architecture pages first, then inspect the main repository's OpenSpec files before changing behavior.

The documentation scaffold stays deliberately brief in this phase. Its job is to make the information architecture navigable now, while leaving room for deeper chapters in later review tasks.
