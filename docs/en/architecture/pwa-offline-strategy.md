# PWA and Offline Strategy

Offline support is a product requirement, not an enhancement. Mind Gym caches the application shell for repeat visits and stores player progress locally so short training sessions remain available even when network quality is poor or nonexistent.

That strategy keeps the game dependable on mobile devices and in low-connectivity environments. It also reinforces the project's privacy posture because routine usage does not require a server round trip.
