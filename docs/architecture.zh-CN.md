# 架构概览

本文档描述 Mind Gym 的系统设计、模块职责与数据流。

---

## 项目形态

| 特性         | 实现方式                           |
| ------------ | ---------------------------------- |
| **部署方式** | 纯静态前端，无需后端               |
| **构建工具** | 无打包器；仅 Tailwind CLI 编译 CSS |
| **框架**     | 无框架，原生 JavaScript (ES2022)   |
| **状态管理** | 内存变量 + localStorage            |
| **PWA**      | Service Worker + Web App Manifest  |

## 模块职责

### 核心模块

| 模块       | 文件                  | 职责                                  |
| ---------- | --------------------- | ------------------------------------- |
| **编排器** | `app.js`              | 游戏主循环、状态机、模式调度、UI 协调 |
| **存储**   | `src/storage.js`      | localStorage CRUD，数据规范化         |
| **统计**   | `src/stats.js`        | 统计数据累计与计算                    |
| **模式**   | `src/modes.js`        | N-back、回忆测验纯逻辑                |
| **成就**   | `src/achievements.js` | 成就定义与解锁检查                    |

### 支撑模块

| 模块         | 文件                   | 职责                      |
| ------------ | ---------------------- | ------------------------- |
| **键名**     | `src/keys.js`          | localStorage 键名常量     |
| **工具**     | `src/utils.js`         | 洗牌、种子随机、HTML 转义 |
| **国际化**   | `src/i18n.js`          | 国际化词典与语言检测      |
| **效果**     | `src/effects.js`       | 音效（Web Audio）与震动   |
| **素材池**   | `src/pools.js`         | 卡面素材池                |
| **计时器**   | `src/timer.js`         | 正计时/倒计时管理         |
| **彩纸**     | `src/confetti.js`      | 胜利粒子动画              |
| **UI**       | `src/ui.js`            | DOM 元素绑定              |
| **UI 事件**  | `src/ui-events.js`     | 事件监听注册              |
| **导入导出** | `src/import-export.js` | 备份数据规范化            |

## 数据流

### 初始化流程

```
DOMContentLoaded
    │
    ├── 绑定 DOM 元素 (ui.js)
    │
    ├── 加载设置 (storage.js)
    │
    ├── 应用主题/强调色/动画设置
    │
    ├── 应用语言 (i18n.js)
    │
    ├── 注册 Service Worker
    │
    └── initGame(difficulty)
            │
            ├── createDeck()
            │
            ├── 渲染卡牌到网格
            │
            └── 重置状态（步数、计时器、提示）
```

### 游戏进行中流程

```
onFlip(card)
    │
    ├── 检查锁定/暂停条件
    │
    ├── 翻牌动画
    │
    ├── 如果是第一张牌:
    │       └── 存储并返回
    │
    ├── 如果是第二张牌:
    │       │
    │       ├── 匹配?
    │       │       ├── 锁定卡牌
    │       │       ├── 更新连击
    │       │       ├── 检查胜利
    │       │       └── 更新进度
    │       │
    │       └── 不匹配?
    │               ├── 延迟后翻回
    │               └── 重置连击
    │
    └── 重置棋盘状态
```

### 结算流程

```
onWin()
    │
    ├── 停止计时
    │
    ├── 更新最佳成绩
    │
    ├── 更新排行榜
    │
    ├── 更新统计
    │
    ├── 更新自适应评分
    │
    ├── 应用间隔复现
    │
    ├── 检查成就
    │
    ├── 显示胜利弹窗
    │
    ├── 运行彩纸动画
    │
    └── 打开回忆测验

onTimeUp()
    │
    ├── 锁定棋盘
    │
    ├── 显示失败弹窗
    │
    └── 更新自适应评分
```

## 性能考虑

### 渲染性能

| 技术           | 实现                            | 收益            |
| -------------- | ------------------------------- | --------------- |
| CSS Transform  | `transform: rotateY()` 翻牌动画 | GPU 加速        |
| CSS Transition | `transition: transform 0.3s`    | 流畅 60fps 动画 |
| Canvas 2D      | `confetti.js` 粒子系统          | 高效粒子渲染    |
| 虚拟列表       | 不适用（固定网格尺寸）          | 此规模无需优化  |

### 内存管理

| 策略       | 实现                                  |
| ---------- | ------------------------------------- |
| 事件委托   | 在容器上使用单一监听器，而非每张卡牌  |
| 定时器清理 | 游戏结束/弹窗关闭时 `clearInterval()` |
| DOM 缓存   | 元素缓存在 `ui.js` 中，不重复查询     |
| 状态重置   | `initGame()` 时重置所有游戏状态       |

## 扩展架构

### 添加新训练模式

1. **逻辑模块** - 添加到 `src/modes.js`
   - 实现纯逻辑函数
   - 接受参数对象，返回结果
   - 不操作 DOM

2. **状态管理** - 添加到 `app.js`
   - 初始化模式状态变量
   - 添加模式控制函数

3. **UI 集成** - 修改 `index.html` + `src/ui.js`
   - 如需则添加模态框
   - 在 `ui.js` 中绑定 UI 元素

4. **国际化** - 更新 `src/i18n.js`
   - 添加模式名称和描述键
   - 中英文均需添加

5. **文档** - 更新 `docs/modes.md`
   - 添加模式规格
   - 包含实现示例

6. **测试** - 创建 `__tests__/newmode.test.js`
   - 测试核心逻辑函数
   - Mock 依赖项

### 添加新卡面主题

1. **素材定义** - `src/pools.js`
   - 添加新主题的 emoji/字符串数组
   - 遵循命名约定

2. **国际化** - `src/i18n.js`
   - 添加主题显示名称翻译

3. **验证器更新** - `src/import-export.js`
   - 更新 `VALID_THEMES` 数组

4. **文档** - 更新相关文档
   - 在 storage.md 主题枚举中列出

## 架构路线图

### 当前状态

- `app.js` 仍然较大（约 2500 行）
- UMD 模块运行良好，但可使用 ES Modules
- 无打包器保持部署简单
