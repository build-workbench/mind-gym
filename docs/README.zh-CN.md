## 📝 文档规范

### 语言约定

- **英文**：技术文档的主要语言
- **中文**：提供 `.zh-CN.md` 变体版本以提升可读性
- **代码**：所有代码示例使用 JavaScript (ES2022)

### 符号说明

| 符号 | 含义 | 示例 |
|------|------|------|
| `<变量>` | 占位符 | `<difficulty>` → `easy` \| `medium` \| `hard` |
| `[可选]` | 可选参数 | `[theme]` |
| `Type[]` | 类型数组 | `string[]` |
| `{key: Type}` | 对象结构 | `{time: number, moves: number}` |

### 版本兼容性

本文档对应 **Mind Gym v1.6.x**。旧版本请参考 [更新日志](../changelog/CHANGELOG.md)。
