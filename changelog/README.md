## 版本号规则

遵循 [语义化版本](https://semver.org/lang/zh-CN/):

| 位置 | 含义 | 递增时机 |
|------|------|----------|
| 主版本号 | 不兼容的 API 变更 | 破坏性变更 |
| 次版本号 | 向后兼容的功能新增 | 新增功能 |
| 修订号 | 向后兼容的问题修复 | 修复问题 |
