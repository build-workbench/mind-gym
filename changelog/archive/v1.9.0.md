# Mind Gym v1.9.0 Release Notes

**Release Date**: 2026-04-28

## 🎯 Overview

This release introduces the **FSRS-4.5 Mastery System**, a modern spaced repetition algorithm for intelligent card theme scheduling.

## ✨ New Features

### FSRS-4.5 Mastery System

- **New Module**: `src/fsrs.js` with core FSRS-4.5 implementation
- **Card Mastery Tracking**: Stability and difficulty metrics for each theme
- **Intelligent Scheduling**: Review scheduling based on retrievability
- **Performance Mapping**: Game performance → FSRS rating (Again/Hard/Good/Easy)
- **Migration Support**: Automatic upgrade from legacy spaced weights

### Technical Implementation
