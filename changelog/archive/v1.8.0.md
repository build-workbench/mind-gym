# Mind Gym v1.8.0 Release Notes

**Release Date**: 2026-04-27

## 🎯 Overview

This release marks the **Final Release** of Mind Gym. The project is now in maintenance-only mode with all critical bugs fixed and documentation consolidated.

## 🐛 Critical Bug Fixes

### isReducedMotion() Logic Fix

- **Issue**: The `isReducedMotion()` function had inverted logic
- **Impact**: Motion preference settings were not working correctly
- **Fix**: Corrected return values for `motion === 'on'` and `motion === 'off'`

### createDeck() Fallback

- **Issue**: Function could return empty array causing game to crash
- **Impact**: Invalid card themes would break the game
- **Fix**: Now falls back to emoji theme when pool is invalid

## 📚 Documentation
