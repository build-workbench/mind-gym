# Mind Gym v1.10.0 Release Notes

**Release Date**: 2026-04-29

## 🎯 Overview

This release focuses on code quality improvements and project documentation enhancement.

## ✨ New Features

### Shared Utilities Module

- **New Module**: `src/shared.js` - Shared utility functions
  - `isPlainObject()` - Check if value is a plain object
  - `clampInt()` - Integer constraint with min/max bounds
  - `clampNumber()` - Number constraint with min/max bounds

### State Management Modules

- **New Module**: `src/game-manager.js` - Card flip/match/win logic
- **New Module**: `src/modal-manager.js` - Modal open/close/focus trap
- **New Module**: `src/settings-manager.js` - User preferences management
- **New Module**: `src/game-state.js` - Runtime game state coordinator
- **New Module**: `src/nback-state.js` - N-back mode state
- **New Module**: `src/recall-state.js` - Delayed recall mode state

## 🔧 Refactoring

### Code Deduplication

- Extracted common functions from 4 modules to `shared.js`:
  - `src/stats.js`
  - `src/modes.js`
  - `src/import-export.js`
  - `src/achievements.js`
- Reduced code duplication by ~40 lines

### Architecture Improvement

- Deep module pattern applied to game state management
- Clear separation of concerns between state layers
- Improved testability with isolated module interfaces

## 📚 Documentation

- Enhanced project documentation structure
- Fixed broken documentation links and references
- Updated module loading order in CLAUDE.md

## ⚙️ Engineering
