# v1.0.0 Core Modularization / 核心模块化

**Release Date / 发布日期**: 2025-12-19

---

## Overview / 概览

First major release with complete modularization of the codebase into 10 UMD modules for better testability and maintainability.

首个主要版本，将代码库完全模块化为 10 个 UMD 模块，提升可测试性和可维护性。

---

## Added / 新增

### UMD Modules / UMD 模块

| Module / 模块 | File / 文件 | Purpose / 职责 |
|---------------|-------------|----------------|
| Keys / 键名 | `src/keys.js` | localStorage key management / 键名管理 |
| Utils / 工具 | `src/utils.js` | Random/shuffle utilities / 通用工具 |
| Storage / 存储 | `src/storage.js` | localStorage read/write / 数据读写 |
| I18n / 国际化 | `src/i18n.js` | Language detection / 语言判定 |
| Effects / 效果 | `src/effects.js` | Sound and vibration / 音效震动 |
| Pools / 素材池 | `src/pools.js` | Card face pools / 卡面素材 |
| Timer / 计时器 | `src/timer.js` | Timer management / 计时管理 |
| Confetti / 彩纸 | `src/confetti.js` | Victory animation / 胜利动画 |
| UI | `src/ui.js` | DOM bindings / DOM 绑定 |
| UI Events / UI 事件 | `src/ui-events.js` | Event bindings / 事件绑定 |

---

## Changed / 变更

### index.html

- Load all `src/` modules before `app.js` / 先加载所有模块

### app.js

- Integrated all module globals / 接入所有模块全局对象
- DOM binding via module calls / DOM 绑定改为调用模块

### src/storage.js

- Added daily challenge status / 每日挑战完成状态
- Added onboarding status / 引导隐藏状态
- Bulk deletion support / 批量删除支持

### sw.js

- Pre-cache all `src/` modules / 预缓存所有模块

### scripts/prepare-deploy.sh

- Copy `src/` to `dist/` on deploy / 部署时复制 `src/`
