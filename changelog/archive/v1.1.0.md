# v1.1.0 Workflow Standardization / 工作流标准化

**Release Date / 发布日期**: 2026-03-10

---

## Overview / 概览

Deep standardization of GitHub Actions workflows with unified naming, permissions, concurrency, and caching.

GitHub Actions 工作流深度标准化，统一命名、权限、并发和缓存。

---

## Changed / 变更

### GitHub Actions

| Change / 变更 | Description / 说明 |
|---------------|--------------------|
| Pages workflow rename / 工作流重命名 | `deploy.yml` → `pages.yml` |
| CI permissions / CI 权限 | `permissions: contents: read` 统一权限 |
| Concurrency / 并发控制 | Added to prevent duplicate builds / 防止重复构建 |
| Pages configuration / Pages 配置 | Added `actions/configure-pages@v5` |
| Path filtering / 路径过滤 | Added `paths` trigger filtering / 减少无效构建 |

---

## Background / 背景

Standardized naming, permissions, concurrency, and caching strategies across all repository workflows.

全仓库 GitHub Actions 深度标准化，统一命名、权限、并发、路径过滤与缓存策略。

## Project Status / 项目状态

CI/CD process standardized, build efficiency improved.

CI/CD 流程标准化，构建效率提升。
